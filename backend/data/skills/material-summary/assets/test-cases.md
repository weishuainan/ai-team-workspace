# 材料总结 — 测试 Case

## Case 1：用户反馈型场景 — 外卖新用户首单转化优化

**输入**：

```
项目名称：外卖新用户首单转化优化
项目目标：找到新用户首单流失的核心节点，并形成可进入需求评审的优化方案
补充背景：最近外卖新注册用户首单转化率持续下降，App Store 也有用户吐槽下单流程复杂

消息记录：
[运营-张思琪 08-12 10:00]：最近收到很多用户反馈，说新用户第一次点外卖的时候不知道怎么用，领了优惠券但是在结账页看不到在哪用。App Store 评论里也有人吐槽。
[运营-张思琪 08-12 10:05]：我统计了一下，上周客服渠道一共收到12条类似反馈，主要集中在"优惠券找不到入口"和"不知道怎么能便宜点"。
[产品-卫帅楠 08-12 10:15]：转化数据确实在降。月初新用户首单转化率是42%，这周一查已经掉到35%了。但是我不确定是不是和上周上线的选餐流程改版有关。
[产品-卫帅楠 08-12 10:20]：我记得之前从进入首页到完成下单平均3分钟，新版本好像变成5分钟了，但这个数据我没太确认。
[运营-张思琪 08-12 10:30]：还有个用户直接在 App Store 评论说"太复杂了，卸载了去用饿了么"，这个挺严重的。
[运营-高文颖 08-12 11:00]：我觉得可以试试在首页直接放首单红包入口，把优惠前置。之前到店业务线试过类似策略，效果还不错。
[产品-卫帅楠 08-12 11:10]：直接放红包入口可能会影响老用户的信息流体验，需要想清楚。不过先搞清楚原因再说。
```

**期望输出要点**：

- `core_facts` 至少 3 条：首单转化率从42%降至35%（source: 卫帅楠, confidence: high）、12条用户反馈（source: 张思琪, confidence: high）、下单耗时从3分钟变为5分钟（source: 卫帅楠, confidence: low — 因为说了"没太确认"）、App Store 有用户评论吐槽（source: 张思琪, source_type: user_feedback）
- `key_viewpoints` 至少 2 条：高文颖建议首页放首单红包入口+优惠前置（is_consensus: false）、卫帅楠担心红包入口影响老用户体验（is_consensus: false）
- `user_problems` 至少 2 条：优惠券找不到入口（severity: high, frequency: frequent）、不知道怎么下单更便宜（severity: medium, frequency: occasional）
- `conflicts`：高文颖主张首页放红包入口 vs 卫帅楠担忧影响老用户信息流体验
- `open_questions`：首单转化率下降是否与选餐流程改版有关？下单耗时数据是否准确？App Store 差评具体是哪些版本后的？
- `coverage_assessment`：一般（有数据有反馈，但缺少更细的下单漏斗分析）
- 不得出现任何 Case 中未提及的数字
- 不得输出"建议"或"方案"
- 用户反馈的 source_type 应为 user_feedback，不可标为 merchant_feedback

## Case 2：数据异常型场景 — 外卖满减活动核销率下降

**输入**：

```
项目名称：外卖满减活动核销率异常分析
项目目标：定位近期外卖满减活动核销率下降的原因并给出优化建议
补充背景：过去两周外卖满减优惠券的核销率持续走低，从15%降到9%

消息记录：
[运营-张思琪 08-12 09:00]：最近两周外卖满减券的核销率一直在跌，从15%掉到9%了。老板让我们赶紧查原因。
[产品-卫帅楠 08-12 09:10]：是哪个渠道发放的券？全渠道都在跌还是特定渠道？
[运营-张思琪 08-12 09:15]：主要是APP首页弹窗发放的券跌得厉害，从20%掉到8%。Push消息和短信渠道基本持平。
[运营-高文颖 08-12 09:20]：我感觉是因为上个月改了弹窗的样式，用户可能没注意到领券入口。不过这个只是猜测。
[产品-卫帅楠 08-12 09:30]：也有可能是满减门槛调整了。上个月开始外卖满减门槛从满20减5改成满30减5了。
[运营-张思琪 08-12 09:35]：对，满减门槛确实调高了，这个是业务侧主动调整的。但弹窗样式我不确定改没改。
[运营-高文颖 08-12 09:40]：弹窗样式确实改了，我记得是08月1号上线的。当时A/B测试的数据我找不到了。
[产品-卫帅楠 08-12 09:45]：那就先按已知的信息整理一下，弹窗样式变更和满减门槛调整都可能是因素，但不排除还有其他原因。
[系统消息 08-12 09:50]：陈静雯加入了项目。
[运营-陈静雯 08-12 10:00]：我补充一下，之前看用户评价和客服工单，有用户说"满减券太少不够用"，也有人说"门槛太高了不划算，不如直接用饿了么"。
```

**期望输出要点**：

- `core_facts`：整体核销率从15%降至9%、APP弹窗渠道从20%降至8%、Push/短信渠道持平、满减门槛从满20改为满30、弹窗样式08月1日上线（confidence: medium — 高文颖说"我记得"但不确定）、用户评价提到券少和门槛高
- `key_viewpoints`：高文颖猜测弹窗样式变更导致（is_consensus: false）、卫帅楠认为满减门槛调整也可能是因素（is_consensus: false）、卫帅楠认为不排除其他原因
- `user_problems`：用户认为满减券太少（severity: medium, frequency: occasional）、用户认为门槛太高不划算（severity: medium）、有用户提到考虑竞品（severity: high）
- `conflicts`：高文颖说弹窗样式改了 vs 张思琪说"不确定改没改"（同一个事实，双方认知不一致，应标注为信息不一致而非观点冲突）
- `open_questions`：弹窗样式是否确实在08月1日变更？A/B测试数据在哪里？是否存在其他未发现的影响因素？
- `coverage_assessment`：一般
- 系统消息不归入任何类别
- 高文颖说"弹窗样式确实改了"和张思琪说"不确定改没改"这个矛盾必须体现
- 陈静雯转述的用户反馈，source 应标注"运营-陈静雯（转述用户评价/客服工单）"，source_type 为 user_feedback
